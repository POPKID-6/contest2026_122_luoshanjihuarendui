# AI Coding 日志

本项目真实开发日志位于 [POPKID-6/](POPKID-6/)，由 Codex Desktop 历史会话转换，按北京时间日期归档。

- 8 个主会话（含协作子线程），14 个 JSONL 文件，共 3574 条事件。
- `POPKID-6/manifest.json` 为会话清单。
- 目录结构：`logs/POPKID-6/YYYY-MM-DD/codex__<session_id>.jsonl`。
- 已通过官方 `validate-log.py` 校验。
- 来源、脱敏、转换方式与历史数据局限见 [转换说明](POPKID-6/README.md)。
