# 厂商音频驱动补丁说明（关键：否则播放无声）

文件：`vendor/allwinnertech/chips/r528/components/audio/sunxi_alsa.c`

## 背景：为什么必须打这个补丁

实测结论（对照实验）：

| 配置 | 结果 |
|---|---|
| 只改上层、不动驱动 | 播放**完全没声音**（`nxplayer` 返回成功） |
| 打上本补丁 | 播放**有声音** ✅ |

根因（逐行核对驱动与 codec 代码得到）：

1. 驱动里唯一设置播放音量的函数 `sunxi_audio_setvolume()`（写 codec 的
   `DACL/DACR digital volume`，numid 6/7）被 `#ifndef CONFIG_AUDIO_EXCLUDE_VOLUME`
   包着，而板级配置原本是 `CONFIG_AUDIO_EXCLUDE_VOLUME=y` → **该函数被整个编译掉**。
2. `sunxi_audio_start()` 中那段 codec 初始化（MIC 开关 + ADC 音量）**只在
   `priv->record`（录音）分支执行**；`else`（播放）分支**什么都不设**。
3. codec 默认参数 `.digital_vol = 0x0`，且 `sunxi_codec_init()` 会把
   `DAC_VOL_SEL` 置 1（切到 DACL/DACR 通道音量）→ 这两个寄存器保持**复位默认值（静音）**。
4. 结果：录音正常（录音路径有初始化），**播放全程无声**。

---

## 补丁 1：播放路径启动时初始化 DAC 音量

位置：`sunxi_audio_start()` 中 `if (priv->record) { ...ADC... }` 之后、
`#endif` 之前，新增 `else` 分支。

```c
	else
	{
		/* PLAYBACK_DAC_VOL_INIT: 播放路径原来不初始化任何 codec 控件，
		 * DACL/DACR 保持复位默认(静音)，导致 nxplayer 播放"成功"却无声。 */
		snd_ctl_set(CONFIG_AW_AUDIO_CODEC_DEFAULT_CARDNAME, "DAC digital volume switch", 1);
		snd_ctl_set(CONFIG_AW_AUDIO_CODEC_DEFAULT_CARDNAME, "digital volume", 0x3F);
		snd_ctl_set(CONFIG_AW_AUDIO_CODEC_DEFAULT_CARDNAME, "DACL digital volume", 0xFF);
		snd_ctl_set(CONFIG_AW_AUDIO_CODEC_DEFAULT_CARDNAME, "DACR digital volume", 0xFF);
		syslog(LOG_INFO, "playback dac volume inited\n");
	}
```

> 说明：`digital volume` 是全局音量（0x3F 满），`DAC digital volume switch=1`
> 选择使用 DACL/DACR 通道音量，两者一起设可覆盖两种选择路径。

## 补丁 2：音量刻度对齐（让上层 `nxplayer_setvolume(1000)` 能到满量程）

位置：`sunxi_audio_configure()` 里 `case AUDIO_FU_VOLUME:` 分支。

```c
		case AUDIO_FU_VOLUME:
			{
			/* VOL_SCALE_FULL: NuttX 音量 0~1000 -> codec DAC 0~255 满量程
			 * （原实现是 hw[0]/10，最大只能到 100/255，会覆盖补丁 1 的 0xFF） */
			uint16_t volume =
				(uint16_t)(((uint32_t)caps->ac_controls.hw[0] * 255) / 1000);
			sunxi_audio_setvolume(priv, volume);
			}
```

## 验证方法

1. 播放时串口/系统日志应出现 `playback dac volume inited`
2. 镜像字节校验：`grep -c "playback dac volume inited" <img>` 应为 1
3. 上板后耳机应能听到 TTS 语音

## 一键检查是否已打补丁

```bash
grep -n "PLAYBACK_DAC_VOL_INIT\|VOL_SCALE_FULL" \
  vendor/allwinnertech/chips/r528/components/audio/sunxi_alsa.c
```
两条都能 grep 到即为已打补丁。
