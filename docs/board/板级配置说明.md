# 板级配置说明（Gemini-S1 / R528）

本目录记录设备端固件所需的**板级配置改动**。这些改动位于 openvela 竞赛分支树
`dev-ai-contest-2026` 中，路径如下（虚拟机内 `/home/ubuntu/openvela-ai`）：

| 改动 | 路径 |
|---|---|
| 编译配置 | `vendor/allwinnertech/boards/r528/r528s3-gemini-s1/configs/kitchen/defconfig` |
| 开机自启 | `vendor/allwinnertech/boards/r528/r528s3-gemini-s1/src/etc/init.d/rcS` |

---

## 1. defconfig（新建 `configs/kitchen/`）

以官方的 `nsh_minidisplay` 配置为基线（那是 2.8" ILI9341 屏已验证的配置），
在末尾追加/修改以下项目：

```ini
# —— 关闭官方 mini 桌面，换成我们的应用 ——
# CONFIG_LUNCHER_MINI_APP is not set

# —— 智能厨房应用 ——
CONFIG_KITCHEN_SMART=y
CONFIG_KITCHEN_SMART_PROGNAME="kitchen_smart"
CONFIG_KITCHEN_SMART_PRIORITY=100
CONFIG_KITCHEN_SMART_STACKSIZE=32768
CONFIG_KITCHEN_SMART_MQTT_HOST="broker.emqx.io"
CONFIG_KITCHEN_SMART_MQTT_PORT=1883
CONFIG_KITCHEN_SMART_DEVICE_ID="device001"
CONFIG_KITCHEN_SMART_WIFI_IFNAME="wlan0"

# —— 网络 / WiFi / 时钟 ——
CONFIG_WIRELESS_WAPI=y
CONFIG_WIRELESS_WAPI_INITCONF=y
CONFIG_NETUTILS_DHCPC=y
CONFIG_NETUTILS_NETLIB=y
CONFIG_LIBC_NETDB=y                 # getaddrinfo 需要（域名解析）

# —— 音频：必须关掉音量排除，否则驱动里设置 DAC 音量的代码被编译掉（会没声音）——
# CONFIG_AUDIO_EXCLUDE_VOLUME is not set
```

> 基线里已有的、本项目依赖的开关（无需改动，仅供核对）：
> `CONFIG_LCD_ILI9341=y`、`CONFIG_LCD_ILI9341_IFACE0=y`（横屏 320×240）、
> `CONFIG_GT911_IIC_TOUCH=y`、`CONFIG_LV_USE_NUTTX_TOUCHSCREEN=y`、
> `CONFIG_LV_USE_FREETYPE=y` + `CONFIG_LIB_FREETYPE=y`（中文显示）、
> `CONFIG_AW_DRIVERS_AUDIO=y`、`CONFIG_AW_AUDIO_CODEC=y`、
> `CONFIG_SYSTEM_NXPLAYER=y`、`CONFIG_SYSTEM_NXRECORDER=y`。

## 2. rcS 开机自启

`src/etc/init.d/rcS` 末尾追加：

```sh
#ifdef CONFIG_KITCHEN_SMART
echo "start kitchen_smart"
kitchen_smart &
#endif
```

## 3. 设备端可选配置文件 `/data/etc/kitchen.conf`

不创建则使用编译期默认值（broker.emqx.io / 1883 / device001 / wlan0）：

```ini
host = broker.emqx.io
port = 1883
device_id = device001
wifi_if = wlan0
```

## 4. WiFi 配置（App 自动写入，无需手工）

App 连上 WiFi 后会把配置写成**厂商 wapi 的嵌套 JSON 格式**到
`/data/etc/wifi/wapi.conf`（该路径与 `CONFIG_WIRELESS_WAPI_CONFIG_PATH` 一致），
因此 `wapi reconnect` 与开机自动重连都能生效：

```json
{
    "wlan0": {
        "mode": 2,
        "auth": 4,
        "cmode": 8,
        "alg": 3,
        "ssid": "你的WiFi名",
        "bssid": "",
        "psk": "你的WiFi密码"
    }
}
```

WiFi 连接采用的完整流程（与厂商脚本一致）：
`ifup → disconnect → WPA2/CCMP 关联（wpa_driver_wext_associate）→ 关省电 → DHCP + 设置掩码/网关/DNS`
